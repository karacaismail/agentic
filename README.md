# Agentic

Bu repo, ajanlarla yazılım geliştirme araştırmalarını tek yerde toplar.
Amaç, görev girişinden doğrulanmış çıktıya kadar bütün süreci tasarlamaktır.

## İçerik

- Ana klasördeki numaralı Markdown dosyaları inceleme raporlarıdır.
- `agents`, `TDD` ve `Oracle-Problem` klasörleri kaynak belgeleri içerir.
- `agent_providers` klasörü model ve sağlayıcı araştırmalarını içerir.
- Diğer harita klasörleri ihtiyaçları, riskleri ve mimari kararları içerir.
- `senaryo-atlasi` ve `fabrika-karar-merkezi` uygulama kaynaklarını içerir.
- `denetim` klasörü inceleme araçlarını ve araştırma sonuçlarını içerir.
- `KAYNAK-ENVANTERI.json`, kopyalanan kaynakların boyutunu ve içerik özetini kaydeder.
